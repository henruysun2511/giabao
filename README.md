# Bao — Chief Technology Officer (CTO) · Cyclosa HRM
### Digital Scrapbook & Playful Neo-Brutalism Portfolio

Portfolio cá nhân của **Bao** — Chief Technology Officer (CTO) tại **Cyclosa HRM**. Định hướng công nghệ, SaaS Multi-Tenant architecture, AI CV Semantic Matcher & Enterprise Data Security.

---

## 🎨 Thiết Kế & Phong Cách
- **Scrapbook A4 Canvas**: Tông giấy ngà `#FDFCF7`, dòng kẻ ngang mờ như vở học sinh, viền đen dày 3px và bóng đổ neo-brutalism (`shadow-[12px_12px_0px_#000]`).
- **Typography**: 
  - Tên/Tiêu đề: Font Pixel 8-bit (`Silkscreen`).
  - Ghi chú/Doodles: Font chữ viết tay (`Caveat`).
  - Nội dung: Font sans-serif hiện đại (`Plus Jakarta Sans`).
- **Điểm nhấn thị giác**:
  - Khung tên cam vẽ tay & sticker mũi tên.
  - 2 khung ảnh phong cách Polaroid kèm dán băng dính Washi Tape bán trong suốt.
  - Danh sách kỹ năng dạng Pill Badges nhiều màu sặc sỡ với icon Lucide React.
  - Khối dự án vát góc dạng tab thư mục hồ sơ (Folder dossiers clip-path polygon).
  - Bưu thiếp liên hệ kèm tem bưu điện và con dấu xác thực.

## 🛠️ Công Nghệ Sử Dụng
- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Ngôn ngữ**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Google Fonts (`Silkscreen`, `Caveat`, `Plus_Jakarta_Sans`)

## 🚀 Chạy Cục Bộ (Local Development)

```bash
# 1. Cài đặt dependencies
npm install

# 2. Khởi chạy dev server
npm run dev

# 3. Mở trình duyệt tại:
http://localhost:3000 (hoặc cổng được hiển thị trên console)
```

## 📦 Build Production

```bash
npm run build
npm run start
```
